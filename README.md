# Dar Zarabi — متحف الزرابي

Walk-through carpet museum for Dar Zarabi (Boujad, Morocco): photoreal medina alleys with the shop's carpets on the walls, a detail panel with sizes and prices, WhatsApp ordering, and "view in your room" (AR) on phones.

Static site served by GitHub Pages from the `main` branch. `index.html` is generated by the build kit kept in the project files; edit there and push the rebuilt page, not by hand.
